1. Create a reusable voice hook

Create a new file: src/hooks/useAuraVoice.ts (or update an existing similar hook if you find one).

Implement a hook with this API:

export function useAuraVoice() {
  return {
    hasSpeechSupport: boolean;
    hasTTSSupport: boolean;
    isListening: boolean;
    isSpeaking: boolean;
    lastTranscript: string;       // final recognized text
    error: string | null;
    startListening(): void;
    stopListening(): void;
    speak(text: string): void;
    stopSpeaking(): void;
    clearTranscript(): void;
  };
}


Implementation details:

Detect STT support

On mount, detect window.SpeechRecognition || window.webkitSpeechRecognition.

If not present, set hasSpeechSupport = false and a friendly error like
"Voice input not supported in this browser."

If present, create one recognition instance, non-continuous, interimResults = false, lang = "en-US" (or use existing config if you already have one).

Recognition lifecycle

startListening():

If no support, set an error and return.

Clear lastTranscript.

Clear previous error.

Call recognition.start() inside try/catch.

Set isListening = true.

stopListening():

If currently listening, call recognition.stop() and set isListening = false.

onresult handler:

Take the final transcript from event.results[0][0].transcript.

Save it into lastTranscript.

onerror:

Set a simple error message like "Mic error: <code>"

Set isListening = false.

onend:

Ensure isListening = false (recognition may stop on its own).

TTS support

On mount, check window.speechSynthesis → hasTTSSupport.

speak(text):

If no TTS support or empty text, do nothing.

Call speechSynthesis.cancel() first to stop any current speech.

Create SpeechSynthesisUtterance(text).

utterance.lang = "en-US".

utterance.rate = 1, pitch = 1.1, volume = 1.

Choose a feminine voice:

Use speechSynthesis.getVoices() and pick the first voice whose name matches
/female|woman|salli|emma|amy|joanna|natasha|sara|aria|luna|zoe|olivia/i

If none, just use voices[0].

Set isSpeaking = true on onstart, and false on onend or onerror.

Call speechSynthesis.speak(utterance).

stopSpeaking():

Calls speechSynthesis.cancel() and sets isSpeaking = false.

clearTranscript() just resets lastTranscript to "".

Make sure the hook never throws on server-side / non-browser environments (guard window access).
